\caption[Query sequence]{Sequence of a user query through the sandbox. The query never runs on the application's pooled
connection: it runs on a separate login as the workspace role, whose privileges reach only that
workspace's schemas, inside a read-only transaction with a statement timeout and a row cap. The run is
then recorded on the pooled connection, where a trigger maintains the saved query's statistics.
